Prompt injection against a SOC triage agent, run twice side by side. The left column has no defenses; the right has the ones you pick.

What the modes mean
  • replay — a real model run recorded earlier. The defenses re-execute on playback, so the toggles still work.
  • live — calls the model now. The same attack lands on some runs and not others.
Defenses for the right column:

What each defense does
  • D1 wraps attacker-controllable text in tags and tells the model it is data. It blocks nothing and the text reaches the model intact — whether it obeys is the model's call, so D1 can fail invisibly.
  • D2 sends a memory write made with untrusted text in context to quarantine instead of long-term memory. Nothing is rejected outright: it waits below for you to approve or reject it.
  • D3 refuses the tool call outright when untrusted text is in context. The run continues and the action never executes — including when the action was the correct one. It records that a human would have to approve it; there is no approval path in this demo.
